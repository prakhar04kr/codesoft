# Cloudspital Interview Notes PDF

Generates a compact 2-page interview prep PDF for the **Cloudspital Health Kiosk Management Platform** project.

## Output

- `Cloudspital_Health_Kiosk_Management_Platform.pdf`

## Regenerate

```bash
pip install reportlab
python3 generate_pdf.py
```

The script writes the PDF to `/opt/cursor/artifacts/` and copies it into this folder.
